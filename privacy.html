홈페이지에서 직접 받는 정보

이 홈페이지에는 회원가입, 상담 입력 양식, 파일 업로드 기능과 자체 방문 분석 도구를 설치하지 않았습니다. 이름·전화번호·채무 내용 등을 홈페이지 양식으로 전송하거나 별도의 상담 데이터베이스에 저장하는 기능이 없습니다.

웹사이트를 제공하는 호스팅 사업자는 서비스 운영과 보안 등을 위해 접속 정보를 처리할 수 있습니다. GitHub Pages의 정보 처리에 대해서는 GitHub 개인정보 처리방침을 확인하실 수 있습니다.

전화·카카오톡 상담

전화 연결 버튼은 이용 기기의 통화 기능을 열고, 카카오톡 문의 버튼은 외부 오픈채팅으로 이동합니다. 통화나 채팅을 시작하면 해당 방식으로 전달하신 정보가 상담 과정에서 처리될 수 있습니다.

초기 문의에는 상담 질문과 연락 가능한 시간 등 필요한 정보만 전달해 주세요. 계좌·금융 비밀번호와 인증번호는 상담 단계와 관계없이 보내지 마세요. 신분증·주민등록번호가 포함된 서류 등 구체적인 사건 자료는 필요한 범위와 안전한 전달 방법을 확인한 뒤 준비해 주세요.

카카오톡은 외부 사업자의 서비스로, 계정·채팅·기기 등의 정보 처리에는 해당 사업자의 정책이 적용됩니다. 카카오 개인정보 처리방침에서 확인할 수 있습니다.

지도와 외부 링크

홈페이지의 지도는 OpenStreetMap의 외부 지도를 불러옵니다. 지도 표시 과정에서 해당 서비스로 접속 정보가 전달될 수 있습니다. OpenStreetMap 재단 개인정보 처리방침을 확인하실 수 있습니다.

네이버 지도 버튼을 누르면 외부 서비스가 열립니다. 지도에서 출발지·현재 위치를 입력하거나 위치 권한을 허용하는 경우 해당 서비스의 정책과 기기 설정이 적용됩니다. 네이버 개인정보 처리방침을 참고해 주세요.
