# 화면·문안·탐색 흐름 검토

기준일: 2026-10-16. 사용자 제공 디자인 3장과 기존 운영 화면, 다음 공식 사이트의 정보 구성을 비교했다. 글로리는 실제 브라우저 화면도 확인했으며, 법승·로앤은 공개 페이지의 정보 구조와 본문을 비교했다. 다른 사무소의 실적·인력·주소·사진을 이 사무소의 정보로 사용하지 않았다.

- [글로리 회생파산센터](https://glorylawfirm.kr/kor/revive/): 첫 화면의 상담 접근, 업무·절차·비용·위치 연결 참고.
- [법승 대전 회생·파산센터](https://www.bslawwin.co.kr/daejeon/center/recovery): 상세 안내의 목차, 신청 요건, 비교·질문 구성 참고.
- [로앤 회생·파산](https://lawandfirm.com/bank/): 자격·절차·비용·서류별 탐색, 상황별 질문과 상담 연결 참고.

## 반영 내용

- 네이비·골드, 원래 로고, 법률 정물 이미지, 아이콘과 사진형 업무 카드로 통일. 실제 건물·직원 사진이 없으므로 해당 사진처럼 보이는 이미지와 간판은 제작하지 않음.
- 첫 화면에서 업무 종류와 상담 방법을 확인하고, 고민 → 제도 → 절차 → 경력·안내 원칙 → 질문 → 위치·연락 순으로 탐색하도록 구성.
- 사용자 제공 `2004년부터 개인회생 업무, 20년 이상` 경력 반영. 집계 근거 없는 상담 건수·인가율은 게재하지 않음.
- 긴 개인회생·개인파산 페이지에 5개 항목 빠른 이동 추가. 공식 법원 안내에 근거한 무담보 10억·담보부 15억 원 이하 기준 명시. 기간·감면율·결과는 보장하지 않음.
- 연달아 나오던 상담 박스를 정리해 페이지 하단의 실제 전화·카카오톡 연결에 집중.
- 성공사례 미공개와 실제 실적 부재를 혼동하지 않도록 문안 수정. 공개 자료가 없는 사건을 사례로 창작하지 않음.
- 작은 금색 글씨를 더 짙게 조정. 흰색 상담 버튼 글자의 배경 대비를 높임. 작은 본문과 업무 카드 글씨를 확대하고 모바일 버튼 터치 영역을 조정.
- 자동 슬라이드·팝업을 사용하지 않음. 고정 헤더 높이를 유지해 화면이 튀지 않도록 하고, 메뉴 Escape 닫기·키보드 포커스·모션 감소 설정을 지원.
- 실제 지도 표시 + 확인한 네이버 목적지 길찾기. 지도 출처와 외부 서비스 개인정보 안내 반영.

## 확인 범위

정적 검사: 고유 메타데이터·H1·canonical, 메뉴, 55개 구조화 데이터 노드, 파일·앵커·이미지, sitemap·robots·CNAME, 상담 양식 부재와 실제 지도 연결.

브라우저 검사: 13페이지 × 320·390·768·1280 너비 총 52개 화면에서 가로 넘침과 H1 확인, 메뉴 열기·Escape 닫기, FAQ, 빠른 이동, 이미지 로딩, 고정 헤더, 실제 지도·네이버 도착지, 카카오톡 사무소 상담방 표시.

전체 접근성 인증이나 실제 이용자 필드 속도 점수를 의미하지 않는다. 실제 검색 색인·소유권·순위는 검색엔진과 소유자 계정에서 별도로 확인해야 한다. 검색 1위는 보장하지 않는다.
