# 법무사 안상재 사무소 홈페이지

운영 주소는 https://criceto.co.kr 입니다. 외부 패키지 없이 Node.js 22 이상으로 정적 페이지를 생성합니다. `src/`의 공통 구성으로 전체 메뉴와 페이지를 유지하고, 생성한 HTML도 함께 커밋합니다.

## 생성·검사·미리보기

```powershell
node scripts/build.mjs
node scripts/check.mjs
node scripts/serve.mjs
```

미리보기: http://127.0.0.1:4173 · 종료: `Ctrl+C`

- `src/home.mjs`: 홈 내용
- `src/content.mjs`: 업무·제도·상담·위치 등 12개 페이지 내용
- `src/guides.mjs`: 상황별 안내 4개 페이지(직장인·자영업자·프리랜서·일용직·투자 손실 채무). 작성일(`published`)을 넣으면 화면 날짜와 Article 구조화 데이터가 함께 생성됩니다.
- `src/parts.mjs`: 페이지 본문에 공통으로 쓰는 섹션·카드·자주 묻는 질문 조각
- `src/site-config.mjs`: 운영 도메인, 실제 발급된 검색 소유권 토큰, 선택적 네이버 지도 설정
- `src/maps.mjs`: 홈·오시는 길의 실제 OpenStreetMap 지도와 검증된 네이버 길찾기 목적지
- `scripts/build.mjs`: 공통 헤더·푸터, 메타데이터·구조화 데이터, 18개 HTML, 사이트맵·RSS(`rss.xml`)·robots 생성
- `css/renewal.css`, `css/reference.css`, `js/renewal.js`: 공통 화면과 메뉴·스크롤 동작
- `css/refine.css`: 마지막에 불러오는 글꼴·글자 크기 기준(본문 17px, 모바일 16px, 가장 작은 안내 13.5px). 글자 크기는 이 파일에서 조정합니다.
- `assets/fonts/`: 본문용 Pretendard와 제목용 명조 부분 글꼴(SIL OFL, `assets/fonts/OFL.txt`). 제목 문구가 많이 바뀌면 `python3 scripts/subset-serif.py <Noto Serif CJK SemiBold 경로>`로 제목용 글꼴을 다시 만들 수 있으며, 다시 만들지 않아도 새 글자는 확장 글꼴로 표시됩니다.
- `assets/renewal/`: 홈페이지에 적용된 이미지

검사는 모든 색인 페이지(현재 17개)와 noindex 404, 고유 제목·설명·canonical, 한국어/H1, 공통 메뉴와 현재 위치, 로컬 파일·앵커·이미지 설명/크기, 구조화 데이터의 주소·전화, 사이트맵·robots·CNAME, 상담 입력폼·전송·저장 기능 부재를 확인합니다. 브라우저에서 데스크톱·모바일 화면, 키보드 메뉴, 링크와 실제 전화·카카오톡 연결을 별도로 확인하세요. 정적 검사는 법률 내용의 적정성, 외부 서비스 응답, 실제 지도 위치나 검색 순위를 보장하지 않습니다.

## 운영 브랜치와 안전한 되돌리기

운영 배포 브랜치는 `csdel-1-patch-1`입니다. 기본 브랜치 `main`은 유지합니다. `main`과 `법무사-최종`은 저장소 설정·기존 연결·배포 의존관계를 확인하고 별도 판단하기 전에는 삭제하지 않습니다.

리뉴얼 전 백업은 `backup/pre-renewal-20261016`, 원본 커밋은 `448124aa333d0f5868320d652c40019262157800`입니다. 운영 변경은 검증한 작업 브랜치에서 반영하며, 배포 후 사이트 내용과 HTTPS·주요 경로를 다시 확인합니다. 문제가 생기면 원인 변경 커밋을 `git revert`로 되돌리고 다시 검사·배포합니다. 공개된 운영 이력을 `reset`이나 강제 푸시로 덮어쓰지 않습니다. 백업 브랜치는 복구 기준으로 보존합니다.

## 네이버 지도·검색 소유권

홈·오시는 길에 실제 OpenStreetMap 지도를 삽입하고 출처를 표시했습니다. 네이버 길찾기 버튼에는 실제 네이버 주소 검색에서 선택·확인한 목적지를 연결했습니다. 네이버 화면에서 출발지와 이동 수단을 선택하세요. 임의 좌표나 모형 지도를 사용하지 않으며, 건물 좌표와 경로의 검증 자료는 `docs/LOCATION-SOURCES.md`에 기록합니다. 지도 표시 시 외부 서비스 연결에 관한 개인정보 안내도 반영했습니다.

네이버 SDK 지도 직접 표시는 현재 Key ID가 없어 사용하지 않습니다. 추후 변경하려면 네이버 클라우드에서 발급한 해당 지도 서비스의 **공개 Key ID**와 허용 웹 도메인을 준비하고, `src/site-config.mjs`의 검증된 숫자형 `officeCoordinates: {lat, lng}`와 `naverMapKeyId`를 설정하세요. 직접 표시용 `js/naver-map.js`는 두 설정이 있을 때만 삽입됩니다. SDK를 활성화할 경우 기존 외부 지도와 표시 컨테이너를 조정하고, 발급 앱의 API·도메인 권한·과금 상태와 실제 표시 위치를 브라우저에서 확인해야 합니다. Secret Key, 계정 토큰, 비밀번호는 공개 저장소에 넣지 않습니다.

네이버 서치어드바이저·구글 서치콘솔은 소유자 계정에서 사이트를 추가하고 실제로 발급받은 토큰만 `naverVerification`/`googleVerification`에 설정합니다. 재생성·배포 후 해당 계정에서 소유권 확인을 완료하고 사이트맵을 제출합니다. 토큰 생성이나 검색 순위 상승을 코드만으로 대신할 수 없으며, 검색 1위는 보장할 수 없습니다.

## 콘텐츠·상담 운영 기준

주소는 대전 서구 둔산중로78번길 40 봉화빌딩 402호, 전화는 010-6429-4797입니다. 상담 액션은 전화와 기존 카카오톡 오픈채팅의 직접 연결 두 가지입니다. 상담 안내 메뉴는 설명 페이지이며, 헤더·홈·성공사례·모바일 하단의 카카오톡 문의하기 버튼은 채팅으로 바로 연결합니다. 홈페이지에는 개인정보 입력폼·첨부·접수 저장·자체 방문 분석 기능을 두지 않습니다. 상담 정보를 받을 필요가 생기면 수집 목적·범위·보관·전달 방식과 실제 개인정보 안내부터 정비하세요.

기존 홈페이지의 성공사례 20건은 `src/cases-data.mjs`에서 원문과 수치를 보존합니다. 원본은 `법무사-최종` 브랜치의 cases.html(blob `d727a576`)이며, 카드가 안내 페이지로 대체되기 전 이력과 전 필드를 대조했습니다. 신규 성공사례·실적·후기는 확인된 자료와 공개 범위를 바탕으로 추가합니다. 이미지는 상징적 공간과 사물로 구성하며 실제 직원·실제 사무실을 촬영한 것처럼 소개하지 않습니다. 법률 정보는 일반 안내이며 신청 가능성·변제금·기간·면책 결과를 보장하지 않습니다. 변경 시 법원 등 공식 안내와 실제 사무소 정보를 확인하세요.

## 검색 노출 관리

- 사이트맵(`sitemap.xml`)과 RSS(`rss.xml`)는 빌드할 때 함께 만들어집니다. 주요 내용을 실제로 수정한 페이지의 `updated`만 수정일로 바꾸고, 기존 `published`는 보존하세요. 전역 `siteUpdated`는 기존 배포의 기본 날짜이므로 재빌드할 때마다 바꾸지 않습니다. 표시 날짜·Article·WebPage·사이트맵의 일치는 `npm run check`로 검사합니다.
- 네이버 서치어드바이저에는 사이트맵과 함께 RSS(`https://criceto.co.kr/rss.xml`)도 제출합니다.
- 배포 후 `node scripts/indexnow.mjs`를 실행하면 바뀐 주소를 IndexNow로 네이버·빙에 알립니다. 루트의 키 파일(`a5c71fa9a1b77007aa2893584c051d30.txt`)은 지우지 마세요.
- 화면에 보이지 않는 키워드 목록이나 지역 이름만 바꾼 페이지는 검색엔진 지침상 스팸으로 처리될 수 있어 만들지 않습니다.
