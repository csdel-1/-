# ⚖️ 법률사무소 웹사이트

## 📌 프로젝트 개요
개인회생·개인파산·법인회생·채무조정 전문 법률사무소를 위한 **전문 법률 웹사이트**입니다.  
`lawus.co.kr` (법률사무소 스타일)와 `happypasan.co.kr` (파산/회생 전문 사무소 스타일)을 참고하여 제작되었습니다.

---

## ✅ 현재 구현된 기능

### 🏠 메인 페이지 (`index.html`)
- **헤더**: 상단 정보바 + 드롭다운 네비게이션 + 스크롤 시 축소 효과
- **히어로 슬라이더**: 2슬라이드 자동 전환, 도트 컨트롤
- **빠른 상담 바**: 전화·카카오·방문 상담 정보 표시
- **서비스 섹션**: 4가지 업무분야 카드 (개인회생·개인파산·법인회생·채무조정)
- **Why Us 섹션**: 다크 배경 + 숫자 카운트업 애니메이션 + 4가지 강점
- **진행 절차**: 5단계 프로세스 시각화 (호버 효과)
- **성공사례**: 3개 카드형 사례 소개
- **고객 후기**: 슬라이더형 리뷰 (이전/다음 버튼)
- **FAQ**: 아코디언 방식 자주 묻는 질문
- **CTA 배너**: 전화·온라인 상담 유도 배너
- **푸터**: 4단 그리드 (브랜드·업무분야·사무소안내·연락처)
- **플로팅 버튼**: 전화상담·무료상담·맨위로 버튼

### 📋 무료 상담 신청 (`consult.html`)
- **온라인 상담 폼**: 성함·연락처·이메일·상담유형·채무규모·연락시간·내용
- **폼 유효성 검사**: 실시간 필드 검증, 에러 메시지 표시
- **API 저장**: 제출 시 `tables/consultations` 테이블에 데이터 저장
- **사이드바**: 긴급전화·방문예약·상담보장 정보

### 🗂️ 업무 분야 (`services.html`)
- **스티키 탭 네비**: 스크롤 위치에 따라 활성 탭 자동 하이라이트
- **4가지 서비스 상세**: 개인회생·개인파산·법인회생·채무조정
- **통계 시각화**: 인가율·감면율·처리기간·처리건수 표시
- **교대 레이아웃**: 좌우 교대 2단 레이아웃

## 📁 파일 구조

```
/
├── index.html          # 메인 페이지
├── consult.html        # 무료 상담 신청
├── services.html       # 업무 분야
├── css/
│   ├── style.css       # 메인 스타일시트 (CSS 변수·공통·섹션별)
│   └── sub.css         # 서브 페이지 스타일
└── js/
    ├── main.js         # 공통 JS (헤더·슬라이더·FAQ·애니메이션)
    └── consult.js      # 상담 폼 검증 및 API 제출
```

## 🗄️ 데이터 모델

### `consultations` 테이블
| 필드 | 타입 | 설명 |
|------|------|------|
| id | text | 고유 식별자 |
| name | text | 신청자 성함 |
| phone | text | 연락처 |
| email | text | 이메일 |
| consult_type | text | 상담 유형 (rehab/bankruptcy/corporate/debt/other) |
| debt_amount | text | 채무 규모 |
| contact_time | text | 희망 연락 시간 |
| message | rich_text | 상담 내용 |
| status | text | 처리 상태 (접수대기/상담중/처리완료) |
